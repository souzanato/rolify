= Rolify Specs

== Running the specs

Install the gems and run the specs against the default ActiveRecord version:

  bundle
  rake

The Appraisals matrix exercises every supported ActiveRecord release. It lives
in the +Appraisals+ file, and the gemfiles under +gemfiles/+ are generated from
it.

  bundle exec appraisal list
  bundle exec rake appraisal                   # runs the default task for each appraisal
  bundle exec appraisal activerecord-8.1 rake  # or a single one

== Model Adapters

Rolify currently supports 2 different ORMs: ActiveRecord and Mongoid. By default it will use Active Record but you can change this by setting the +ADAPTER+ environment variable before running the specs. You can run the +bundle+ command with this as well to ensure you have all the required gems.

  ADAPTER=mongoid bundle
  ADAPTER=mongoid rake

The Mongoid suite needs a MongoDB server listening on +localhost:27017+:

  ADAPTER=mongoid BUNDLE_GEMFILE=gemfiles/mongoid_9.gemfile bundle exec rake

The different model adapters you can specify are:

* active_record (default)
* mongoid

You can also run the +spec_all+ rake task to run specs for each adapter.

  rake spec_all
